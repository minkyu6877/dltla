# QR ㄱ자 주행 — 기존 보정값 공유

실행: `python3 qr_auto_roundtrip_gui.py --headless`

GUI: `http://10.44.212.72:8085`

## 경로와 배치

- 좌표는 로봇1 중심 기준이다. UWB는 이 프로그램에서 비활성화한다.
- 로봇1: (0,0), +y 방향. 로봇2: 같은 방향으로 로봇1 뒤에 배치한다.
- 시작 초음파 간격을 약 30cm로 맞춘다. 기존 중심 오프셋 19.4cm를 더해
  중심 간격 약 49.4cm로 초기화한다. R2 초기 좌표는 약 (0,-0.494)이다.
- 아무 QR이나 3프레임 연속 인식하면 두 로봇이 출발한다.
- (0,3)까지 직진 → 두 로봇 정지 → R1 시계 90° 자전/R2 공전 →
  +x 방향으로 (4,3)까지 직진 → 두 로봇 정지.
- (0,3)에 조기 진입하는 곡선은 없다. 각도는 R1 IMU, 직진 좌표는
  엔코더+IMU 추정치로 판정한다. 정지 허용오차가 있어 물리적으로 정확한
  3m/4m/90°를 보장하는 절대위치 제어는 아니다.
- 기본은 편도다. 자동 복귀를 출발 전에 선택하면 180° 전환 후 같은 ㄱ자
  경로로 복귀하고 초기 방향을 복원한다. 이번 90° 시험에는 선택하지 않는다.
- 코너 공전 중 R2는 x<0 영역을 지난다. 차체까지 고려해 여유 공간을 확보한다.
- 재출발 전 두 로봇을 반드시 처음 위치/방향으로 옮긴다. QR은 치웠다 다시 보여준다.

## 기존 보정값이 적용되는 위치

| 항목 | 적용 위치/값 |
| --- | --- |
| 바퀴별 모터/엔코더 부호, RPM PID, 마찰 보정 | 현재 ESP32 펌웨어 유지. 재업로드/추가 곱셈 없음 |
| 바퀴 반지름 | `wheel_radius_m=0.03` (지름 6cm) |
| 차체 회전 기하 | 반축간 0.097m + 반윤거 0.15m = K 0.247m |
| IMU yaw 부호 | `imu_yaw_signs=[-1,-1]` |
| 공전 횡이동 배율 | `orbit_tangent_scale=1.10` |
| 공전 거리 보정 | kp 0.012, 상한 0.04, ±2cm 데드밴드, 변화율 0.06/s |
| 공전 RPM 회전 동기화 | kp 0.002, 최대 보정 0.04 |
| 공전 엔코더 누적 방향 보정 | kp 0.14, 최대 보정 0.05 |

공전 구간은 `robot_control_gui.RobotCore`의 실험용 계산을 그대로 호출한다.
계산 전용 인스턴스는 UDP 소켓을 만들거나 명령을 전송하지 않는다.
전송/엔코더+IMU 위치 갱신은 `FormationSystem` 하나만 담당한다.
따라서 실험 계수를 별도의 `formation_orbit_*` 값으로 재해석하지 않는다.
수동 GUI의 기존 `formation_*` 설정은 그대로 유지한다. 이 자동 경로의
직진 추종은 아래의 초음파+IMU 방식으로 분리했다.

## 2026-08-30 실측 후 추가 보정

- 로봇1 중심 실측 2.70m / CSV 정지 후 y=2.96088m에서
  첫 보정 `auto_route_forward_odometry_scales=[0.9118910594, 1.0]`을 얻었다.
  추가 실측 후 현재 값은 아래의 **0.8738671085**로 갱신했다.
  이 프로그램의 로봇1 **차체 전진** 엔코더 거리 환산에만 곱한다.
  로봇2, 후진, 횡이동, IMU 및 ESP32의 RPM 목표/PID/부호는 변경하지 않는다.
  단일 구간에서 얻은 경험적 보정으로, 다른 바닥/속도에서도 정확함을 보장하지 않는다.
- 기존 CSV의 공전 후 약 40cm 추정 위치 오차는 R2의 가속 명령으로 이어졌다.
  이제 자동 직진은 R1 속도 명령과 IMU 방향을 따라가며 초음파 간격으로
  전후 속도를 최대 ±0.04 보정한다. 좌표 오차를 추종 명령에 넣지 않는다.
  R2 좌표는 엔코더+IMU **추정치**로 그대로 표시/기록하며 임의로 재설정하지 않는다.
  초음파 하나로 옆 방향 위치나 앞 물체의 정체를 알 수는 없다.
- 초음파는 출발 간격을 계속 목표로 사용한다. 동일한 거리 필터/이상값 판정을
  직진에도 사용하고, 기본 28cm부터 R2 병진을 줄여 24cm 이하에서는 병진을
  금지한다. 18cm 이하에서는 여전히 두 로봇 안전정지한다.
  R1 정지 중에는 간격/좌표 오차를 따라 R2가 혼자 전진하지 않는다.
- 공전 마지막 30°는 두 로봇 명령을 함께 감속한다(최소 55%).
  정지 후 R1/R2 각각 목표 방향으로 작은 제자리 회전을 수행한다.
  두 IMU가 각각 목표 ±1°, 상호 방향 차이 1° 이내이며 자이로 회전속도
  2°/s 이하에서 1초 유지돼야 다음 직진으로 넘어간다.
  12초 내 정렬 실패/센서 이상이면 정지하며 자동 재시작하지 않는다.
- 직진 시작은 0.60 command/s로 증가시킨다. 기본 직진 0.30은 유지한다.
- GUI `적용 중 보정값`의 `forward_odometry_scales`를 확인한다.
  CSV에 거리 환산, 직진 간격 제어, 공전 감속배율과 `TURN_ALIGN` 단계를 기록한다.

## 영상1 확인 후 추가 수정 — precision-v2

- 로그 `auto_roundtrip_20260830_181442.csv`의 첫 직진 정지 후 y=2.97401m,
  사용자 실측 약 2.85m(15cm 짧음)를 근거로 현재 R1 전진 환산은
  `0.9118910594 × 2.85 / 2.97401 = 0.8738671085`이다.
  실측이 '약 15cm'이므로 이 값도 잠정 보정이다. R2/횡이동/후진 배율은 그대로다.
- 직진 마지막 30cm는 속도 0.20으로 접근하고, 조기 도착 허용 6.5cm를 3cm로
  줄였다. 정지 후 `_STOPPED` 로그를 남긴다. 종점 초과/횡오차/방향오차가 크면
  자동 후진으로 되돌리지 않고 정지한다. 정확한 절대위치 보장을 뜻하지 않는다.
- 로그상 다음 직진 시작 때 R1 +1.8°, R2 -1.5°가 기존 조건을 통과했다.
  이를 막도록 위 정렬 조건을 강화하고, 관성 예측 및 회전 최소입력 0.05를
  사용한다(기존 0.035에서 수 초간 RPM이 0인 기록 확인).
  공전 중에도 기존 엔코더 동기 보정에 IMU 상대방향 보정(입력 최대 ±0.025)을
  추가한다. 직진 때 R2는 R1만이 아니라 경로의 목표 방향도 유지한다.
- GUI 주황색 R2는 **초음파가 R1 후면 중심을 본다는 조건의 편대 추정**이다.
  R1 좌표/두 IMU/초음파로 계산하고, 중심 오프셋 19.4cm를 전후 절반씩 나눈
  대칭 센서 배치를 가정한다. 실제 센서·반사점 배치가 다르면 이 추정도 오차가 난다.
  초음파 하나로 측면 위치/장애물 정체를 관측할 수 없어 실제 절대좌표로 간주하지 않는다.
- 원래 R2 엔코더 누적 좌표는 수정하지 않고 CSV/API의 `follower`에 유지한다.
  화면 체크박스로 회색 십자 표시가 가능하다. 편대 추정은 `follower_relative`와
  별도 CSV 열에 저장하고 **주행 제어에는 사용하지 않는다**.
  센서 단절·간격 이상·과도한 각도·거리 급변 확인 중에는 주황 추정을 숨긴다.
  지도 x/y의 1m 길이를 같은 픽셀 수로 맞춰 각도/궤도 표시 왜곡도 줄였다.
- 자이로/R2 편대 추정/안전정지를 발생시킨 원시 간격을 CSV에 추가했다.
  IMU 표시가 맞아도 실제 방향이 다르면 IMU 바이어스/회전 배율을 별도 실측해야 한다.
  이번에는 영상의 약 95°만으로 IMU 값을 강제로 5° 수정하지 않았다.

최근 유효 1m 시험은 2026-08-27 21:52:57(R1), 21:53:53(R2) 두 건이다.
중심 좌우 오차는 각각 0.25cm/0.8cm, 차축 실측 각도는 1.48°/2.95°였다.
이 파일들은 시간별 엔코더 누적량 대신 요약 통계만 저장했다. 이 자료만으로
새 거리 환산 계수를 확정하거나 IMU 배율을 임의로 추정해 적용하지 않았다.
확정 적용된 펌웨어/설정 보정값과 실험 결과 수치는 구분한다.

## 기본값·안전·검증 범위

- 직진 명령 0.30, GUI 범위 0.20~0.50. 공전 횡이동 0.22, 회전 요청 0.10.
- 명령값은 기존 ESP32 프로토콜의 속도 입력이며, 정확한 실측 m/s 보장은 아니다.
- R1 펌웨어 장애물 정지 유지. R2 초음파 18cm 이하 정지, 공전 거리 이탈
  15cm 초과 정지, 센서 단절/각도 급변/반대 회전/시간 초과 시 중단한다.
- 각 구간의 정지와 공전 종료는 R1만 정지하지 않고 ORBIT 모드를 해제해
  두 로봇 모두 STOP 한다. 경로 작업이 0.6초 이상 멈추면 전송 제어도 정지한다.
- 다른 수동/실험/자동 GUI는 동시에 실행하지 않는다.
- GUI의 '적용 중 보정값'과 CSV의 공전 보정 항목에서 실제 사용값을 확인한다.
- 자동화 테스트는 비구동 상태머신/명령 계산 검증이다. 실제 주행 검증은 별도다.
